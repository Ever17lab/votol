x--------------------------KP/KI--------------------------
Рассчитайте коэффициенты KP и KI (с высокой точностью)
Крутящий момент [Н·м]; KP, макс. ток разряда при конкретном напряжении = мощность / напряжение (округление в большую сторону)
Крутящий момент = KP * ток

KP = 10 * KI
ПРИМЕЧАНИЕ: Увеличение крутящего момента снижает максимальную скорость, и наоборот.

Рассчитайте MTPA для текущего рабочего напряжения
Kv = номинальная_скорость / напряжение (номинальная_скорость — скорость при отключенных режимах ослабления поля и 3-скоростном режиме)
Базовый MTPA: MTPA ~ (Kv/60) * напряжение (мотор-колесо)
Расширенный MTPA: MTPA ~ (Kv/60) * напряжение * пары_полюсов * КПД (кареточный мотор)
--------------------------Напряжение-----------------------
Минимальное напряжение запуска: 29,5 В
Минимальное рабочее напряжение: 19,5 В
-------------------------Калибровка--------------------------
Слабая калибровка (Weak calibration): относится к току Vd/Id (неверные настройки влияют только на диапазон ослабления поля)
-------------------------Фаза--------------------------
sw 2.33
Фаза, стр. 1: ограничение тока Iq
1 единица фазы = 0,01 А.
Значение фазы указывается на один MOSFET. Для контроллеров серии 100s (3 FET на плечо), макс. фаза 9960 => макс. фазный ток 422 А
Мин. фаза (для 50-80s): 232
Макс. фаза = Id + Iq
Если Id + Iq > макс. фазы => Макс. Id, Iq = 1/2 макс. фазы
Угол датчика Холла влияет на напряжение Vd
--------------------------Расширенные функции--------------------------
1, Рекуперативное торможение (~Datbike Quantum) (ВИДЕО VINO)
Настройка порта PD15 SW-ON (выкл. = нет рекуперации при отпускании газа) (переключает отрицательное значение Id)
Уменьшение параметров Traction Control/TC2 (диапазон 20–9000; значения ниже 9000 снижают фазный ток)
Настройка интенсивности снижения скорости / рекуперативного торможения (0–255)
Нельзя использовать одновременно с функцией усиления движения (booster)

2, Калибровка спидометра (не рекомендуется; лучше калибровать на самом спидометре) (ВИДЕО VINO)
(GPS/Спидометр) * 64 * 256 ; значение по умолчанию 9428 <=> коэффициент GPS/спидометр 0,575

3, Автокруиз (в стадии тестирования)
4, Термостат двигателя
PA0 — датчик внешней температуры
И провод датчика (серо-белый), и термостат подключены к выводу PA0, поэтому можно использовать любой из них, но не оба одновременно
5, Lamehome
функция ограничения оборотов на уровне 50% от максимума; может работать совместно с кнопкой e-gear или круиз-контроля
6, Функции LY (в стадии тестирования)
7, Аварийная остановка (в стадии тестирования)
